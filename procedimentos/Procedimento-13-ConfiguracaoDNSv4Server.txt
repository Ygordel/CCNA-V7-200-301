!======================================================================
! CONCEITO - DNSv4
!======================================================================

! O DNS (Domain Name System) é responsável por realizar a associação
! entre nomes utilizados pelos serviços de rede e seus respectivos
! endereços IP.

! Dessa forma, os usuários e aplicações podem utilizar nomes em vez
! de memorizar diretamente os endereços IPv4 ou IPv6 dos servidores.

! Exemplo:
!
! server-02 -> 192.168.3.1


!======================================================================
! PORTAS UTILIZADAS PELO DNS
!======================================================================

! O DNS utiliza normalmente a porta UDP 53 para consultas realizadas
! pelos clientes.

! Porta utilizada para consultas DNS:
! UDP 53

! O protocolo TCP também pode ser utilizado na porta 53 em situações
! que exigem comunicação TCP, como determinadas operações relacionadas
! à transferência de zonas.

! Porta TCP utilizada pelo RNDC (Remote Name Daemon Control):
! TCP 953


!======================================================================
! TIPOS DE ZONA DNS
!======================================================================

! Zona de pesquisa direta:
!
! Realiza a resolução de um nome para um endereço IP.
!
! Exemplo:
!
! server-02 -> 192.168.3.1


! Zona de pesquisa reversa:
!
! Executa o processo inverso, relacionando um endereço IP ao
! respectivo nome DNS.


!======================================================================
! REGISTROS DNS
!======================================================================

! Os registros DNS armazenam informações utilizadas pelo servidor
! durante o processo de resolução de nomes.

! Alguns registros comuns são:

! A
! Associa um nome a um endereço IPv4.

! AAAA
! Associa um nome a um endereço IPv6.

! CNAME
! Cria um nome alternativo (alias) para outro nome DNS.

! NS
! Identifica o servidor DNS responsável por uma zona.

! SOA
! Contém informações de autoridade e parâmetros administrativos
! relacionados à zona DNS.

! MX
! Identifica servidores responsáveis pelo recebimento de e-mails.

! PTR
! Utilizado principalmente em consultas DNS reversas.

! SRV
! Permite identificar serviços associados a determinados nomes.

! TXT
! Armazena informações textuais relacionadas ao domínio.


!======================================================================
! LIMITAÇÕES DO CISCO PACKET TRACER
!======================================================================

! O servidor DNS disponibilizado pelo Cisco Packet Tracer possui
! recursos simplificados quando comparado a uma implementação real.

! Para este laboratório:

! - O serviço DNS deve ser ativado manualmente;
! - A configuração está concentrada na pesquisa direta;
! - Os registros disponíveis no simulador são limitados;
! - Serão utilizados registros A, CNAME, NS e SOA.


!======================================================================
! CONFIGURAÇÃO DO DNS SERVER
!======================================================================

! Ativação do serviço:

DNS Service:       On


! Registro A do servidor DNS:

Resource Records:  Name = server-02
                   Type = A Record
                   Address = 192.168.3.1


! Registro NS indicando o servidor responsável pela zona:

Resource Records:  Name = ns1.vaamonde.pti
                   Type = NS
                   Server Name = server-02


! Registro SOA referente à autoridade da zona:

Resource Records:  Name = vaamonde.pti
                   Type = SOA
                   Primary Server Name = ns1.vaamonde.pti
                   Mail Box = vaamonde@vaamonde.pti
                   Minimum TTL = 3600
                   Refresh Time = 3600
                   Retry Time = 600
                   Expiry Time = 86400


! Registro CNAME para o domínio principal:

Resource Records:  Name = vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias para o serviço Web:

Resource Records:  Name = www.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias para o serviço POP3:

Resource Records:  Name = pop3.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias para o serviço SMTP:

Resource Records:  Name = smtp.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias para o serviço FTP:

Resource Records:  Name = ftp.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias para o serviço TFTP:

Resource Records:  Name = tftp.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias utilizado para o serviço NTP:

Resource Records:  Name = ntp.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Alias destinado ao serviço de Logs:

Resource Records:  Name = log.vaamonde.pti
                   Type = CNAME
                   Host Name = server-02


! Registro A do Switch Layer 2:

Resource Records:  Name = sw-l2-2960-3
                   Type = A Record
                   Address = 192.168.3.250


! Registro A do segundo Switch Layer 2:

Resource Records:  Name = sw-l2-2960-4
                   Type = A Record
                   Address = 192.168.3.251


! Registro A do Switch Layer 3:

Resource Records:  Name = sw-l3-3560-1
                   Type = A Record
                   Address = 192.168.3.252


! Registro A do Router:

                   Type = A Record
                   Address = 192.168.2.254


!======================================================================
! CONSULTAS DNS NO MICROSOFT WINDOWS
!======================================================================

! Exibe as informações básicas de configuração da interface de rede.

ipconfig


! Apresenta informações completas da configuração TCP/IP, incluindo
! servidores DNS configurados no computador.

ipconfig /all


! Realiza uma consulta DNS para descobrir o endereço associado ao
! nome do servidor.

nslookup server-02


! Consulta a zona DNS utilizando o domínio configurado no laboratório.

nslookup vaamonde.pti


! Testa a comunicação utilizando o nome DNS em vez do endereço IPv4.

ping vaamonde.pti


!======================================================================
! SEQUÊNCIA SUGERIDA PARA VALIDAÇÃO
!======================================================================

! 01 - Conferir as configurações de rede:

ipconfig /all


! 02 - Consultar o servidor utilizando o nome do host:

nslookup server-02


! 03 - Consultar o domínio configurado:

nslookup vaamonde.pti


! 04 - Testar a resolução de nomes utilizando ICMP:

ping vaamonde.pti
