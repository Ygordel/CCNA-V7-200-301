! Configurar e verificar o recurso AAA (Authentication, Authorization
! and Accounting) utilizando os protocolos TACACS+ e RADIUS.

! A atividade demonstra:

! - Autorização de acesso;

! - Configuração do Console;
! - Verificação das configurações AAA.


!======================================================================
! 02 - AAA
!======================================================================

! AAA significa:

! Authentication  = Autenticação
! Authorization   = Autorização
! Accounting      = Contabilização

! O AAA permite centralizar o controle de acesso aos equipamentos
! e serviços da infraestrutura de rede.


!======================================================================
! 03 - RADIUS
!======================================================================

! RADIUS (Remote Authentication Dial-In User Service) é um protocolo
! utilizado para gerenciamento centralizado de autenticação,
! autorização e contabilização.

! O RADIUS utiliza UDP.

! Porta tradicional de autenticação:

! UDP 1812

! Porta tradicional de contabilização:

! UDP 1813

! Também podem existir implementações utilizando:

! UDP 1645
! UDP 1646


!======================================================================
! 04 - TACACS+
!======================================================================

! TACACS+ (Terminal Access Controller Access-Control System Plus)
! é um protocolo utilizado para autenticação e controle de acesso
! a equipamentos de rede.

! O TACACS+ utiliza:

! TCP 49


!======================================================================
! 05 - CONFIGURAÇÃO DO SERVIDOR AAA
!======================================================================

! No Cisco Packet Tracer, o serviço AAA deve ser habilitado
! diretamente no servidor.

! Configuração:

Service                 On


! Usuário utilizado no laboratório:

Username                pti
Password                pti


! Chave compartilhada:

Secret                  pti

!======================================================================
! 07 - CONFIGURAÇÃO DO SWITCH LAYER 3 3560
!======================================================================

! Acessando o modo EXEC Privilegiado:

enable


! Acessando o modo de Configuração Global:

configure terminal


! Habilitando o modelo AAA:

aaa new-model


! Configurando autenticação de Login:

aaa authentication login default group tacacs+ local


! Configurando autenticação para o modo EXEC Privilegiado:

aaa authentication enable default group tacacs+ local


! Configurando autorização do modo EXEC:

aaa authorization exec default group tacacs+ local


! Configurando contabilização das sessões:

aaa accounting exec default start-stop group tacacs+


! Configurando o servidor TACACS+:

tacacs-server host 192.168.3.1 key pti


!======================================================================
! 08 - CONFIGURAÇÃO DAS LINHAS VTY
!======================================================================

! Acessando as linhas VTY:

line vty 0 5


! Utilizando a lista padrão de autenticação AAA:

login authentication default


! Habilitando contabilização das sessões:

accounting exec default


! Retornando ao modo anterior:

exit


!======================================================================
! 09 - CONFIGURAÇÃO DO CONSOLE
!======================================================================

! Acessando a linha Console:

line console 0


! Utilizando autenticação AAA:

login authentication default


! Habilitando contabilização:

accounting exec default


! Retornando ao modo EXEC Privilegiado:

end


! Salvando as configurações:

write


!======================================================================
! 10 - SWITCH LAYER 2 2960
!======================================================================

! O recurso AAA utilizado neste laboratório depende da versão
! do IOS disponível no Switch.

! Para utilizar os recursos apresentados, o laboratório considera
! a utilização do IOS 15.


! Copiando o IOS para a memória Flash:

enable

copy tftp: flash:


! Endereço do servidor TFTP:

192.168.3.1


! Arquivo IOS:

c2960-lanbasek9-mz.150-2.SE4.bin


! Configurando o IOS para inicialização:

configure terminal

boot system c2960-lanbasek9-mz.150-2.SE4.bin

end


! Salvando as configurações:

write


! Reiniciando o Switch:

reload


!======================================================================
! 11 - CONFIGURAÇÃO AAA DO SWITCH LAYER 2 2960
!======================================================================

enable

configure terminal


! Habilitando AAA:

aaa new-model


! Configurando autenticação de Login:

aaa authentication login default group tacacs+ local


! Configurando autenticação do modo EXEC Privilegiado:

aaa authentication enable default group tacacs+ local


! Configurando autorização:

aaa authorization exec default group tacacs+ local


! Configurando contabilização:

aaa accounting exec default start-stop group tacacs+


! Configurando servidor TACACS+:

tacacs-server host 192.168.3.1 key pti


! Configurando as linhas VTY:

line vty 0 5

exit


! Configurando o Console:

line console 0

login authentication default

accounting exec default

end


! Salvando as configurações:

write


!======================================================================
! 12 - CONFIGURAÇÃO DO ROUTER 1941-2
!======================================================================

! Neste equipamento será utilizado o servidor RADIUS.

enable

configure terminal


! Habilitando AAA:

aaa new-model


! Configurando autenticação de Login:

! Configurando contabilização:

aaa accounting exec default start-stop group radius


! Configurando o servidor RADIUS:
