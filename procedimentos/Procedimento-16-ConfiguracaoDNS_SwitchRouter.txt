!======================================================================
! 01 - RESOLUÇÃO DE NOMES
!======================================================================

! A resolução de nomes permite utilizar identificadores como nomes de
! equipamentos em vez de informar diretamente seus endereços IPv4.

! Exemplo:

! Nome:
! servidor

! Endereço IPv4:
! 192.168.3.1


!======================================================================
! 02 - ACESSANDO O MODO DE CONFIGURAÇÃO
!======================================================================

! Acessando o modo EXEC privilegiado:

enable

! Acessando o modo de configuração global:

configure terminal


!======================================================================
! 03 - HABILITANDO A RESOLUÇÃO DE NOMES
!======================================================================

! Habilitando o recurso de resolução de nomes no Cisco IOS:

ip domain-lookup

! Esse recurso permite que o equipamento realize consultas de nomes
! utilizando os mecanismos de resolução configurados.


!======================================================================
! 04 - CONFIGURANDO O SERVIDOR DNS
!======================================================================

! Definindo o endereço IPv4 do servidor DNS utilizado pelo equipamento:

ip name-server 192.168.3.1

! Servidor DNS utilizado no laboratório:

! DNS Server: 192.168.3.1


!======================================================================
! 05 - CRIANDO UM REGISTRO LOCAL
!======================================================================

! Criando uma associação local entre nome e endereço IPv4:

ip host servidor 192.168.3.1

! Associação criada:

! Nome: servidor
! IPv4: 192.168.3.1

! O registro local permite utilizar o nome do equipamento sem depender
! exclusivamente de uma consulta ao servidor DNS.


!======================================================================
! 06 - SALVANDO A CONFIGURAÇÃO
!======================================================================

! Retornando ao modo EXEC privilegiado:

end

! Salvando a configuração:

write


!======================================================================
! 07 - VISUALIZANDO A CONFIGURAÇÃO
!======================================================================

! Visualizando somente as linhas relacionadas a IP:

show running-config | include ip

! O caractere Pipe (|) permite aplicar filtros aos comandos show.

! Exemplos de filtros:

! include  - apresenta linhas que possuem determinada informação
! exclude  - remove linhas que possuem determinada informação
! begin    - inicia a visualização a partir de determinado trecho
! section  - apresenta uma seção específica da configuração


!======================================================================
! 08 - VISUALIZANDO OS HOSTS CONHECIDOS
!======================================================================

! Visualizando os nomes e endereços conhecidos pelo equipamento:

show hosts


!======================================================================
! 09 - TESTANDO A RESOLUÇÃO DE NOMES
!======================================================================

! Testando o registro local:

ping servidor

! Testando um nome que deverá ser resolvido pelo DNS:

ping server-02

! Testando outro equipamento da infraestrutura:

ping sw-l2-2960-3


!======================================================================
! 10 - TESTANDO O ACESSO SSH UTILIZANDO NOME
!======================================================================

! Utilizando o nome do equipamento para realizar uma conexão SSH:

ssh -l admin sw-l2-2960-3

! O equipamento deverá conseguir resolver o nome informado para o
! endereço IPv4 correspondente antes de estabelecer a conexão.


!======================================================================
! 11 - PRINCIPAIS COMANDOS
!======================================================================

! ip domain-lookup
! Habilita a resolução de nomes.

! ip name-server
! Define o servidor DNS utilizado pelo equipamento.

! ip host
! Cria uma associação local entre nome e endereço IPv4.

! show hosts
! Exibe os hosts conhecidos pelo Cisco IOS.

! show running-config | include ip
! Filtra informações relacionadas a IP na configuração.

! ping
! Permite testar resolução de nomes e conectividade IP.

! ssh
! Permite estabelecer uma conexão remota utilizando SSH.


!======================================================================
! 12 - CONFIGURAÇÃO COMPLETA
!======================================================================

! Sequência principal utilizada no laboratório:

enable

configure terminal

ip domain-lookup
ip name-server 192.168.3.1
ip host servidor 192.168.3.1

end

write


!======================================================================
! 13 - VERIFICAÇÃO E TESTES
!======================================================================

! Verificando a configuração:

show running-config | include ip

! Visualizando os hosts conhecidos:

show hosts

! Testando a resolução e conectividade:

ping servidor
ping server-02
ping sw-l2-2960-3

! Testando acesso remoto:

ssh -l admin sw-l2-2960-3
